# RentApartments

Simple static site skeleton in Hebrew (RTL) with pages:

- `index.html` - עמוד הבית
- `about.html` - אודות
- `apartments.html` - רשימת דירות
- `contact.html` - צור קשר
- `css/style.css` - סגנונות
- `images/` - תמונות נכסים (מקום לשים קבצים)

To preview, open `index.html` in a browser or run a simple static server e.g. `python -m http.server` from the project root.
